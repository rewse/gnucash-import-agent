# JRE Bank Statement Import

Script: [`scripts/jre_bank_import.py`](../../../../../scripts/jre_bank_import.py)

## Accounts

- Source: `Assets:JPY - Current Assets:Banks:JRE Bank`

## Access

Open `https://sfes.rakuten-bank.co.jp/MS/main/RbS?CID=M_START&CMD=LOGIN&BAAS_CODE=JRE` with `agent-browser --auto-connect`, then ask the user to complete the manual login and secret-question (`合言葉`) authentication. Open `入出金明細`, select `以前のお取引`, and extract the page with:

```bash
agent-browser --auto-connect eval "document.querySelector('body').innerText"
```

Use the transaction section between the table header and the CSV download section. The page exposes all transactions without pagination; CSV and PDF downloads are also available.

## Source-specific Rules

- `内)本給` / `BasePay` and `内)職務` / `JobAllow` break down `基本給` / `BaseComp`; `通勤手当 計` / `Travel` restates `非課税通勤` / `NTravel`. Do not add these as separate splits.
- Before executing the replacement SQL, verify that every applicable payslip item has the payslip-backed `value`, all split values balance, JPY-account quantities equal their JPY values, and the AWSome Awards quantity is the supported point count in the `Reward` commodity. Verify that only the bank split is `c`, every payroll counter-split is `n`, and the transaction description is `AWS Japan`.
- AWSome Awards arrive as points and are taxed at receipt. Put the payslip JPY deduction in `value`; put the point count in `quantity` for the `Reward` commodity account. Estimate the count from the deduction divided by the month's USD rate, not the later redemption rate, and cross-check grant emails where available. Do not substitute an amount from another month or an unsupported point count.
- Redemption uses 8 points per JPY 1,000 Amazon gift card. Book any difference between taxable value and redemption value when redeemed. If the point count cannot be established at payroll import, retain the payslip JPY value and correct quantity at redemption.
- Non-payroll transaction descriptions generated by the script are NULL. The manually constructed payroll transaction uses `AWS Japan` as shown in the mapping table.
