# MUFG Bank Statement Import

Script: [`scripts/mufg_bank_import.py`](../../../../../scripts/mufg_bank_import.py)

## Accounts

- Source: `Assets:JPY - Current Assets:Banks:MUFG Bank`

## Access

Open `https://directg.s.bk.mufg.jp/APL/LGP_P_01/PU/LG_0001/LG_0001_PC01` with `agent-browser --auto-connect`, then ask the user to log in manually. Open `入出金明細`, choose the required period, and extract the page with:

```bash
agent-browser --auto-connect eval "document.querySelector('body').innerText"
```

The default period is `最近30日間`; use `期間指定` and the `tx-start-date` and `tx-end-date` inputs for a custom range. Extract rows between the table header and footer. Other period options are `本日`, `最近10日間`, `今月`, and `前月`.

## Statement Data

The extracted table has `YYYY年` headers. Each transaction is a tab-separated line followed by `メモ内容`. Columns are date, withdrawal, deposit, description, balance, and optional memo controls.

```text
2025年
2/17		1,000 円	利息　ス－パ－フツウ	50,000 円
メモ内容

4/28	80,000 円		口座振替４　メイジヤスダセイメイ	70,000 円
メモ内容

7/13		23,456 円	振替　ＥＸＡＭＰＬＥ	78,901 円
メモ内容

7/13	60,000 円		ＰＥ／ＩＮ　ラクテンソンガイホケン	60,000 円
メモ内容
```

Paste this shape directly into `RAW_DATA`. A `YYYY年` line sets the year. A transaction starts with `M/D` or `MM/DD`; preserve empty tab fields. Strip commas, spaces, and `円`; withdrawal is negative and deposit is positive. Skip blank and `メモ内容` lines.

## Mapping

Personal self-transfer classification comes from `transfer_rules.mufg_bank.self_transfer` in `../personal.json`; use [`../personal.example.json`](../personal.example.json) only as its schema. It applies only when the statement description contains a transfer marker (`振込` or `ことら送金`) and the configured `contains` value. Do not put personal names or account paths in this document.

| Statement pattern | Account | Description |
|---|---|---|
| `メイジヤスダセイメイ` | `Expenses:Insurances:Property Insurances` | NULL |
| `ラクテンソンガイホケン` | `Expenses:Insurances:Property Insurances` | NULL |
| `利息` | `Income:Interest Income` | NULL |

Ask for a mapping when no pattern matches. Transaction descriptions generated by the script are NULL.

## Source-specific Rules

The statement page contains at most 100 transactions. Select a narrower custom period when additional pages would otherwise be required.
